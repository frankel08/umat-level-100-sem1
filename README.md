## ⚙️ Repository Rules & Workflow

1. **Terminal Only:** Push coursework files via the command line (`git add`, `git commit`, `git push`).
2. **Conventional Commits:** Write clean commit messages (e.g., `feat: solve mesh analysis circuit problem 4`, `notes: add linear algebra matrix summary`).
3. **Keep Binaries Out:** Ensure compiled executables (`.exe`, `.out`, `.o`) are ignored via `.gitignore`.
